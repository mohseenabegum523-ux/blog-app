# Blog App using Node.js and MySQL

## About the Project
This is a simple Blog Application developed using HTML, CSS, JavaScript, Node.js, Express.js, and MySQL.

## Features
- User Registration
- User Login and Logout
- Create Blog Posts
- Edit Blog Posts
- View Blog Posts
- Delete Blog Posts

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL
- XAMPP and phpMyAdmin

## Installation and Setup
1. Install Node.js and XAMPP.
2. Start MySQL using XAMPP.
3. Open phpMyAdmin and import `database.sql`.
4. Open the project folder in VS Code.
5. Run `npm install` in the terminal.
6. Run `node server.js`.
7. Open `http://localhost:3000` in your browser.

## Database
Database name: `blogdb`
